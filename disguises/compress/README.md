# Compress

A photo compressor: pick photos, set the quality and an optional target size in KB, compress, then save to Photos or share. It runs fully offline; `allowedHosts` is empty.

The target size field takes the code: type it as the size, then hold Compress. A tap never submits a code, and a wrong code compresses as usual.

Peer dependencies: `react`, `react-native`, `react-native-gesture-handler`, `expo-image-manipulator`, `expo-image-picker`, `expo-media-library` and `expo-sharing`.
